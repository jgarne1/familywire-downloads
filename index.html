Getting started

  1. Install FamilyWire. On Mac, unzip and place the app in Applications.
  2. Enter your name and the family code Jeremy gives you.
  3. Click a person to open a private chat, or choose a conversation under Chats.

Your family code is private and is not included in these downloads. Use the same code on your own computers to keep your identity.

Already installed?

On Windows 1.0.1 or newer, open Settings → App updates → Check for updates. Download, then Restart & install. Your name, family code and local chats should carry over. If a 1.5.0 preview says it uses manual downloads, install the Windows download above once to move to the automatic-update release. Windows 1.5.3 includes five themes, shared browsing, a shared Whiteboard, chat archive/restore and previous-name recognition. It includes the 90-session Spanish course, offline bilingual chat practice, English/Spanish interface choices, Math Adventure, Cipher Run and Fleet Duel. Translation is included in this Windows upgrade and stored for offline use. Shared browsing responds faster for either person controlling it, has a clear new-tab button and a close button on each tab, and offers Reload. Mac downloads remain on version 1.4.0. Quick chat remains the starting point, with games and learning available when you want them. Connect Four and play-money Texas Hold'em are also available.

Windows and Mac demos are unsigned. Windows may show an unrecognized-app SmartScreen warning. Signing is still being prepared.

Chat history and server attachments are kept for up to 48 hours on isolated FamilyWire storage. Mac demo apps are unsigned; automatic Mac updates require a signed release.
