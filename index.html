Getting started

  1. Install FamilyWire. On Mac, unzip and place the app in Applications.
  2. Enter your name and the family code Jeremy gives you.
  3. Click a person to open a private chat, or choose a conversation under Chats.

Your family code is private and is not included in these downloads. Use the same code on your own computers to keep your identity.

Already installed?

On Windows 1.0.1 or newer, open Settings → App updates → Check for updates. Download, then Restart & install. Your name, family code and local chats should carry over. The latest release adds a quieter interface and a visible Updates button.

Windows and Mac demos are unsigned. Windows may show an unrecognized-app SmartScreen warning. Signing is still being prepared.

Early demo release. Chat history and server attachments are kept for up to 48 hours. Free hosting can take a moment to wake up and may lose server history sooner on restart. Mac demo apps are unsigned; automatic Mac updates require a signed release.
